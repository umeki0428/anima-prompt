# シーン文の書き方ルール

`prompts/scene-to-composition-ja.md` / `prompts/comfyui-scene-to-prompt.md` に渡す日本語の書き方。
このシーン文の役割は「絵コンテ担当に判断材料を渡す」こと。構図は向こうが決めるので、こちらは状況と感情だけを書く。

## 型

例:「放課後の教室で、男子が机に手をついて迫って、女子が椅子ごと後ずさりしている」

## 入れるもの

| 要素 | 書き方 | 必須 |
|---|---|---|
| 動作 | 「〜しかけている」「〜されている」の進行形。静止形(立っている/見ている)は避ける | ○ |
| 主役の感情 | 一人に絞る。「困っている」「照れている」「見下している」 | ○ |
| 場所 | 一語でいい。「レジで」「教室で」「ベッドで」 | ○ |
| 時間帯 | 光と色を決めたいときだけ。「夕方の」「深夜の」 | △ |
| 関係 | 距離感・力関係の判断材料。「上司と部下」「初対面」 | △ |

## 入れないもの

- **容姿・服装** — キャラ定義の仕事。書くと自然文に容姿が混ざる(容姿は一度だけルール違反)
- **カメラ・構図・アングル** — 絵コンテ担当が決める。決め打ちしたいときだけ「男性の背中越しで」と1語足す
- **曖昧語** — 「かわいく」「エロく」「いい感じに」。判断材料にならないので、感情か動作に言い換える

## 長さ

1〜2文。3文以上は情報過多で構図が平均化される。要素が多いときは主役の感情だけ残して削る。

## 弱い / 強い

| 弱い | 強い |
|---|---|
| 女性が困っている | 女性がレジ打ち中に男性にナンパされて困っている |
| 2人が見つめ合っている | 男性が顔を近づけてきて、女性が目を逸らしかけている |
| ベッドで抱き合っている | 男性が上から覆いかぶさり、女性が両手で胸を押し返している |
| 女性が怒っている | 女性が男性を見下ろして、冷たく笑っている |

強い側は「動作の瞬間」「誰が優位か」「視線の向き」が入っているので、絵コンテ担当の判断手順(感情の主役→関係→小道具→カメラ→瞬間)がそのまま埋まる。

## 時間帯を書いたときに出るもの

| 時間帯 | 光・色 |
|---|---|
| 朝 | 淡い白〜青白、横から差す光 |
| 昼 | フラット、影が薄い |
| 夕方 | 橙、逆光・リムライトになりやすい |
| 夜(室内) | 暗い地色、暖色の弱い光 |
| 夜(屋外) | 青黒、街灯の点光源 |

書かない場合は感情から自動で決まる(困惑→寒色、照れ→暖色)。それで足りる場面が多いので、時間が状況の一部になっているときだけ書く。
「夜」は暗くなりすぎることがあるので、雰囲気優先なら「夜、ランプの明かりで」と光源を添える。
