# img2img で構図を固定する

プロンプトの抽選で構図が出ないとき、元画像で構図を固定する手段。「構図を良くする」のではなく「構図の抽選をやめて固定する」。生成設定は [settings.md](settings.md)、構図の考え方は [composition.md](composition.md)。

## denoise の帯【実生成で一部確認 2026-09-07】

| denoise | 残るもの | 用途 |
|---|---|---|
| 0.3〜0.5 | 構図・ポーズ・配置がほぼ完全に残る。画風・線・色も残る | 微修正。モノクロ元だと灰色が残留 |
| 0.55〜0.7 | 配置・大きさ・向きの大枠は残り、画風・色・細部はプロンプト側 | 構図固定+キャラ差し替えの本命帯 |
| 0.75〜 | ほぼ txt2img。色の塊程度しか残らない | 元画像はヒント程度 |

手元の `anima-img2img.json` は 0.3 / 0.5 / 0.7 を同一 seed で3並列出力する構成なので、1回で帯の比較ができる。

うまくいく条件: 人物の位置・大きさ・前後関係レベルの再現 / 元画像とプロンプトが矛盾していない(配置は同じ、中身だけ差し替え)。
うまくいかない条件: モノクロ→カラー(denoise を上げないと色が乗らず、上げると構図が溶ける)/ 頭身の大きく違うキャラへの差し替え / 指や顔の向きの細部。

## 元画像の種類別

### 落書きラフ(線のみ)
- 構図情報としては完成品と同等に使える(img2img が拾うのは線の質でなく「どこに何の塊があるか」)
- ただし白紙+細線は色情報ゼロなので、低 denoise で白っぽく、高 denoise で消える
- **対処: 5分でいいので大まかに着色する**(人物=肌色の塊、服=適当な色、机=茶、背景=壁色)。色の塊ができると 0.6〜0.7 でも構図が保持される
- 着色なしなら 0.5 前後から
- プロンプトはラフと同じ構図を二重に言う。ラフと矛盾する指示(ラフは横向きなのに `looking at viewer`)は中 denoise で喧嘩する
- ネガの `sketch, monochrome, greyscale` は必須(入力自体が sketch)

### 漫画コマ(モノクロ完成品)
- 吹き出し・効果音・コマ枠は事前に消す(文字がノイズとして残る)
- ネガに `monochrome, greyscale` 必須
- 0.6 でも灰色が残るときは、元画像に大まかな色を置いてから再実行

### Clip Studio の 3D デッサン人形【未検証・最有力】
- カメラ位置そのもの(俯瞰の度合い、OTS、切り取り)を 3D で決めてスクショ→ img2img 0.5〜0.6
- ControlNet がない Anima でカメラを厳密に制御する現実的手段。ラフ+着色の上位互換

## Qwen-Image-Edit との2段構成【未検証】

編集モデルは構図保持が目的の設計なので、img2img より構図が残る。

1. Qwen-Image-Edit 2511 で「この漫画コマをカラーのアニメ塗りに描き直す。構図・ポーズ・カメラは維持」→ カラー版を作る(モノクロ問題もここで解消)
2. それを Anima の img2img に denoise 0.35〜0.45 で通し、画風とキャラ LoRA だけ上書き

## LoRA を img2img に入れる

`UNETLoader → LoraLoaderModelOnly → KSampler`。CLIP が別系統(qwen_3_06b_base)なので ModelOnly 版。strength はまず 1.0、元画像の顔が残る分 txt2img より効きが弱く感じたら 1.1〜1.2。

検証時は **LoRA なし→あり の順**で回す。LoRA を先に入れると「構図が崩れたのが denoise のせいか、LoRA が学習ポーズに引いたせいか」が混ざる。

## 漫画1ページの再現

1発では無理(コマごとにカメラが違う。1枚として処理すると要素がコマをまたいで混ざる。小コマは解像度不足で顔が潰れる)。

手順: Clip Studio でコマごとに切り出し(吹き出し・効果音は消す)→ 各コマを縦横比に合わせて 1〜1.5MP で個別 img2img → コマごとにプロンプト(画像→日本語変換を1コマ1指示で使う)→ 元のページテンプレートに配置し吹き出しを乗せ直す。

コマの難易度: 1人・顔の一部・パース単純(口元アップ等)= 易 / 2人が向き合う全身= 中(`facing another, hug, kiss`)/ 物だけのコマ= 易だがキャラ LoRA が人物を入れたがるので `no humans` 必須 / 効果音= 生成せず手で乗せる。

同じ工程は自作ラフのページにそのまま使える。商業作品のページは練習・検証用途に留める。
