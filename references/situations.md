# 状況・シチュエーションのタグ集

「出来事」「直前・直後」「ハプニング」「成人向けの状況」を **Danbooru 実在タグ**で書くための語彙。
tagpick の辞典(`C:\AI\tagpick\mydict.md` の「状況：〜」)と同じ内容(2026-09-14、297件)。
WD14 eva02-v3 のタグ表、またはプロンプト大辞典の投稿数200以上で照合済み。ここに無い語は原則 Danbooru に無いので、自然文で書く。

## 使い方

- タグ行の **人数の直後**に状況タグを置く(`1girl, 1boy, hetero, netorare, cheating (relationship), ...`)。行為・体位 → 体 → 表情 → 効果 → カメラ → 場所の順は [anima-rules.md](anima-rules.md) と同じ
- 状況タグは1〜3個まで。物語的な説明(「彼氏に見せるため」等)は絵にならないので書かない。自然文には「男がスマホを彼女の顔に向けている」のような**絵になる事実**だけ
- 感情は実在タグで置き換える: 拒絶 → `pushing away, struggling, holding another's wrist, covered mouth, legs together, covering breasts` / 涙・恐怖 → `crying with eyes open, streaming tears, furrowed brow, wince, scared, nervous sweating` / 諦め → `empty eyes, hollow eyes, expressionless`
- NTR は男を1人にする(複数だと破綻)。ネガに `2boys, multiple boys`
