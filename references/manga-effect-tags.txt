TAG REFERENCE (manga effects for Anima)
Rules for using this list: effects the user asked for are mandatory. Beyond that, judge the scene and add what a manga artist would draw, using SCENE DEFAULTS below. Total 1 to 3 items per image. Prefer the "tag" column for the tag line; use the "phrase" column only inside the sentences. Everything not listed here stays out.
VOICE RULE: if the woman's voice is audible (moaning, gasping, crying out, panting with a voice), the tag line must contain: japanese text, plus the clause "small handwritten moan lettering floats beside her mouth". Never spell the characters.
Verified 2026-09-11: Anima cannot spell Japanese lettering (every kana request rendered as random kana). Latin-letter lettering renders. Screentone / monochrome words turn the picture black-and-white and are banned.
