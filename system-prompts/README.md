# system-prompts（ComfyUI の Claude 翻訳ノード用）

ComfyUI のワークフローは、ここにあるテキストを `AnimaLoadTextFile` ノードで読み込む。
**直すときはこのフォルダのテキストだけを編集する**（保存すれば次の実行から反映。ワークフローは触らない）。

| ファイル | 使うワークフロー（workflows/00_現役） | 何をするか | 日本語の書き方 |
|---|---|---|---|
| `01_場面を英語に_8項目.txt` | `1_通常生成_8項目` | 日本語の場面（8 項目）→ タグ＋英文。頭・目線・腕・脚・カメラを 1 つずつ訳す。場所を書かなければ暗いグラデ背景、文字は出さない | 8〜10 行。最低でも「どんな瞬間か・姿勢・構図」。tagpick の「シーン組み立て」タブで作れる |
| `02_決めコマ_効果自動.txt` ＋ `references/manga-effect-tags.txt` | `2_決めコマ_効果自動` | 構図を Claude が決め、ハート・汗・効果線を自動で足す。背景はグラデ固定 | 2〜4 行。1 行目=時間と接触面、2 行目=動作と感情、3 行目=欲しい効果、4 行目=固定したい構図。文字を後入れにするなら「文字なし」と書く |
| `03_anytest用_場面.txt` | `3_anytest_参考画像あり` | 参考画像が構図を決める前提。カメラ語を書かず、誰が・何を・服・表情・色と光だけ | 2〜5 行。構図は書かない |
| `03b_anytest用_追記.txt` | `3_anytest_参考画像あり` | 足したい要素だけを短い英語にする。「効果音」「吹き出し」「効果線」と書くと出る | 1〜3 行 |
| `04_追記翻訳.txt` | （必要なら `1_通常生成` に足す） | 既存プロンプトに足す短い断片だけ訳す | 1〜3 行 |

API キーはワークフローに書かない。環境変数 `ANTHROPIC_API_KEY` を設定する（ノードの api_key 欄は空）。
